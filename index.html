Panduan Integrasi Supabase

Realtime Database

Langkah mudah menghubungkan katalog caregiver & log catatan harian TemanLansia ke Supabase.

1 Buat Project di Supabase

1. Buka https://supabase.com dan login atau buat akun gratis.
2. Klik "New Project", beri nama misalnya temanlansia-db, tentukan password database, dan pilih Region terdekat (Singapore).
3. Masuk ke menu SQL Editor di sidebar dashboard, paste dan jalankan (RUN) schema di bawah ini:

schema.sql (Tabel caregivers & daily_logs) 
-- 1. Tabel Caregivers
CREATE TABLE public.caregivers (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  name TEXT NOT NULL,
  role TEXT NOT NULL,
  city TEXT NOT NULL,
  area TEXT NOT NULL,
  category TEXT NOT NULL CHECK (category IN ('Medis', 'Sahabat Harian')),
  gender TEXT NOT NULL CHECK (gender IN ('Wanita', 'Pria')),
  age INT NOT NULL,
  languages TEXT[] NOT NULL DEFAULT '{}',
  price TEXT NOT NULL,
  price_val INT NOT NULL,
  rating NUMERIC(2,1) DEFAULT 5.0,
  reviews_count INT DEFAULT 0,
  badge TEXT NOT NULL,
  lat DOUBLE PRECISION NOT NULL,
  lng DOUBLE PRECISION NOT NULL,
  image_url TEXT NOT NULL,
  description TEXT,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 2. Tabel Buku Catatan Harian (Daily Logs)
CREATE TABLE public.daily_logs (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  patient_name TEXT NOT NULL DEFAULT 'Ibu Sudarmi (72 th)',
  caregiver_name TEXT NOT NULL,
  time_wib TEXT NOT NULL,
  category TEXT NOT NULL, -- 'Vital', 'Nutrisi', 'Dokumentasi', dll.
  blood_pressure TEXT,
  spo2_pulse TEXT,
  headline TEXT NOT NULL,
  description TEXT NOT NULL,
  photo_url TEXT,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 3. Aktifkan Row Level Security (RLS) & Public Read Policy
ALTER TABLE public.caregivers ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Caregivers publik dapat dibaca" ON public.caregivers
  FOR SELECT USING (true);

ALTER TABLE public.daily_logs ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Daily logs publik dapat dibaca" ON public.daily_logs
  FOR SELECT USING (true);
CREATE POLICY "Daily logs publik dapat diinput" ON public.daily_logs
  FOR INSERT WITH CHECK (true);

3 Contoh Query: Ambil Caregiver & Kirim Log Harian

Berikut adalah fungsi JavaScript siap pakai untuk mengambil katalog caregiver dari database dan menyimpan laporan log harian baru secara live:

queries.js (Read, Insert & Realtime Subscription) 
// A. Ambil data Caregiver dari Supabase dengan filter
async function fetchCaregiversFromSupabase(city = 'all') {
  let query = supabase.from('caregivers').select('*').order('rating', { ascending: false });
  
  if (city !== 'all') {
    query = query.eq('city', city);
  }

  const { data, error } = await query;
  if (error) {
    console.error('Gagal mengambil data caregiver:', error);
    return [];
  }
  return data;
}

// B. Masukkan Catatan Harian (Daily Log) Baru
async function insertDailyLogToSupabase(logPayload) {
  const { data, error } = await supabase
    .from('daily_logs')
    .insert([{
      patient_name: logPayload.patient || 'Ibu Sudarmi (72 th)',
      caregiver_name: logPayload.caregiver || 'Siti Rahayu, S.Kep',
      time_wib: new Date().toLocaleTimeString('id-ID', { hour: '2-digit', minute: '2-digit' }) + ' WIB',
      category: logPayload.category || 'Vital',
      blood_pressure: logPayload.blood_pressure || '120/80 mmHg',
      spo2_pulse: logPayload.spo2_pulse || '98% • 75 bpm',
      headline: logPayload.headline || 'Pemeriksaan Rutin Sore',
      description: logPayload.description || 'Kondisi stabil, minum teh hangat bersama caregiver.'
    }])
    .select();

  if (error) console.error('Gagal simpan log:', error);
  else console.log('Log berhasil disimpan ke Supabase:', data);
}

// C. Realtime Listener: Terima Log Baru Otomatis
function subscribeToDailyLogs(onNewLog) {
  return supabase
    .channel('public:daily_logs')
    .on('postgres_changes', { event: 'INSERT', schema: 'public', table: 'daily_logs' }, payload => {
      console.log('Log baru diterima secara live:', payload.new);
      if (typeof onNewLog === 'function') onNewLog(payload.new);
    })
    .subscribe();
}
